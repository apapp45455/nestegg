連接富邦證券

讓寵物每天自動讀取你的成交紀錄。NestEgg 只會登入與查詢，程式裡沒有任何下單功能。

  1. 準備富邦證券帳戶

    已經有帳戶就直接下一步。還沒有的話可以線上開戶。

  2. 申請網頁憑證，匯出 .pfx 檔

    1. 打開富邦的「金鑰管理與憑證匯出」頁，用身分證字號與電子交易密碼登入
    2. 申請「網頁憑證」，輸入手機或 Email 收到的 OTP；憑證核發後才能匯出
    3. 匯出憑證存成 .pfx 檔，放在固定的地方（匯出密碼預設是身分證字號）

    富邦的憑證管理程式（TCEM.exe）只支援 Windows；Mac 用網頁憑證就可以。

  3. 安裝富邦 Node.js SDK

    到富邦 SDK 下載頁下載 Node.js 版的 zip（不用解壓縮），再選擇它：

    SDK 屬於富邦、沒有開放散布的授權條款，所以不隨 NestEgg 打包，要請你自己下載。

  4. 簽署 API 申請書，當天完成連線測試

    1. 富邦官網 → 客戶服務 → e櫃台 → 簽署項目 →「應用程式介面(API)服務申請書暨聲明書」→ 前往簽署 → 確認。狀態會變成「待測試」
    2. 當天 24:00 前做一次連線測試：在 NestEgg 專案資料夾執行 node tools/fubon-connection-check.cjs，用帳號密碼登入一次（Windows 也可以用富邦的連線測試小幫手）
    3. 看到「…此訊息表連線測試成功」就完成了，API 會在隔天 9:00 前開通

    詳見富邦的線上簽署 SOP。

  5. 建立唯讀的 API Key

    回到「金鑰管理與憑證匯出」頁，按「新增金鑰」：

    • 權限只開帳務查詢，不要開交易下單。就算金鑰外洩，也沒有人能拿它下單。
    • IP 限制：家裡網路的 IP 常會變動，可以先留空。
    • Secret Key 只會顯示一次，建立後馬上複製起來。

  6. 連線並同步

    API 開通後（簽署隔天 9:00 起）再做這一步。

    憑證檔
    尚未選擇

    身分證字號、API Key 與憑證密碼會用系統鑰匙圈加密，只存在這台電腦，用來每天自動同步一次。Mac 第一次同步時會詢問 NestEgg 能否使用鑰匙圈，請選「永遠允許」。

成交紀錄不含手續費，所以本金會略少一點。如果之前已經用 CSV 匯入過同一段期間的紀錄，請擇一來源，以免重複。
