連接永豐金證券

透過永豐官方的 Shioaji API 讀取你的持倉與已實現損益。NestEgg 只會登入與查詢帳務，程式裡沒有任何下單功能。

  1. 準備永豐金證券帳戶

    已經有帳戶就直接下一步。還沒有的話請看永豐的開戶說明（交割帳戶要用永豐銀行）。

  2. 建立唯讀的 API Key

    到永豐理財網的 API 管理頁 按「新增 API KEY」，通過手機或 Email 驗證後設定權限：

    • 勾「行情／資料」「帳務」「正式環境」
    • 不要勾「交易」。就算金鑰外洩，也沒有人能拿它下單。
    • IP 限制：家裡網路的 IP 常會變動，先不要設定，不然 IP 一變就連不上。
    • Secret Key 只會顯示一次，建立後馬上存起來。

    只查帳務不用下載 CA 憑證，也不用簽署 API 約定書、做模擬下單測試（那些是下單才需要的）。

  3. 安裝 Shioaji 命令列程式

    到 Shioaji 的 GitHub 下載頁下載檔名有 macOS（Apple 晶片選 aarch64、Intel 選 x86_64）或 Windows 的壓縮檔，不用解壓縮，再選擇它：

  4. 連線並同步

    API Key 與 Secret Key 會用系統鑰匙圈加密，只存在這台電腦，用來每天自動同步一次。Mac 第一次同步時會詢問 NestEgg 能否使用鑰匙圈，請選「永遠允許」。

永豐的 API 查不到過去的成交紀錄，所以 NestEgg 用「目前持倉」加上「已實現損益」拼回買賣紀錄：還沒賣的股票用持倉的平均成本計算，每次同步會整批更新。 這個串接是照永豐公開的文件寫的，還沒用真實帳戶驗證過；同步結果怪怪的請回報。
