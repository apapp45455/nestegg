連接富邦證券

讓寵物每天自動對帳你的富邦持股。NestEgg 只會登入與查詢，程式裡沒有任何下單功能。

  1. 準備富邦證券帳戶

    已經有帳戶就直接下一步。還沒有的話可以線上開戶。

  2. 申請網頁憑證，匯出 .pfx 檔

    1. 打開富邦的「金鑰管理與憑證匯出」頁，用身分證字號與電子交易密碼登入
    2. 申請「網頁憑證」，輸入手機或 Email 收到的 OTP；憑證核發後才能匯出
    3. 匯出憑證存成 .pfx 檔，放在固定的地方（匯出密碼預設是身分證字號）

    富邦的憑證管理程式（TCEM.exe）只支援 Windows；Mac 用網頁憑證就可以。

  3. 安裝富邦 Node.js SDK

    到富邦 SDK 下載頁下載 Node.js 版的 zip（不用解壓縮），再選擇它：

    SDK 屬於富邦、沒有開放散布的授權條款，所以不隨 NestEgg 打包，要請你自己下載。

  4. 簽署 API 申請書，當天完成連線測試

    1. 富邦官網 → 客戶服務 → e櫃台 → 簽署項目 →「應用程式介面(API)服務申請書暨聲明書」→ 前往簽署 → 確認。狀態會變成「待測試」
    2. 當天 24:00 前做一次連線測試：在 NestEgg 專案資料夾執行 node tools/fubon-connection-check.cjs，用帳號密碼登入一次（Windows 也可以用富邦的連線測試小幫手）
    3. 看到「…此訊息表連線測試成功」就完成了，API 會在隔天 9:00 前開通

    詳見富邦的線上簽署 SOP。

  5. 建立唯讀的 API Key

    回到「金鑰管理與憑證匯出」頁，按「新增金鑰」：

    • API 權限勾「證券業務」，不要勾「證券下單」。就算金鑰外洩，也沒有人能拿它下單。「行情」可勾可不勾。
    • IP 限制：家裡網路的 IP 常會變動，可以先留空。
    • Secret Key 只會顯示一次，建立後馬上複製起來。
    • 金鑰有到期日，到期後同步會暫停並提醒你，再建立一把新的就好。

    NestEgg 每天用這把金鑰查你目前的持股，和上次比對：股數變多就記一筆買進、變少就記一筆賣出，日期是發現變化的那天（電腦沒開的日子會晚幾天，寵物有 7 天寬限，不太受影響）。

  6. （選用）匯入過去的成交紀錄

    不需要過去的紀錄就跳過這一步，只開「證券業務」就能同步，不用開「證券下單」。這樣你目前的持股會記成今天買進，寵物從蛋開始養。

    想讓寵物從你真正開始投資的那天算起，就需要過去的成交紀錄。富邦要有「證券下單」權限才查得到，所以：

    1. 另外建立一把勾「證券業務」＋「證券下單」的金鑰
    2. 貼到下面的「歷史匯入用 API Key」。它只在這次連線時用一次，不會儲存
    3. 匯入完成後，回富邦的金鑰管理頁把這把金鑰刪除

    起始日之前就買的股票，會記成今天買進。之前用 CSV 匯入過同一段期間的富邦紀錄的話，請擇一來源，以免重複。

  7. 連線並同步

    API 開通後（簽署隔天 9:00 起）再做這一步。

    憑證檔
    尚未選擇

    身分證字號、API Key 與憑證密碼會用系統鑰匙圈加密，只存在這台電腦，用來每天自動同步一次；歷史匯入用 API Key 用完就丟，不會儲存。Mac 第一次同步時會詢問 NestEgg 能否使用鑰匙圈，請選「永遠允許」。

匯入的過去成交紀錄不含手續費，所以本金會略少一點；之後每天對帳用的是富邦的成本價。如果之前已經用 CSV 匯入過富邦的紀錄，請擇一來源，以免重複。
