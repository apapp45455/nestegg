連接 Interactive Brokers（盈透）

透過 IB 官方的 Flex Web Service 下載你的成交紀錄。這個服務只能下載報表，金鑰本身沒有下單能力，NestEgg 程式裡也沒有任何下單功能。

  1. 準備 IB 帳戶

    登入 IB 的 Client Portal。下面的選單名稱以英文介面為準。

  2. 建立 Activity Flex Query

    到 Performance & Reports → Flex Queries，在「Activity Flex Query」旁按「+」建立一個新的查詢：

    • Query Name：隨意，例如 NestEgg
    • Sections：只勾 Trades。Options 選 Executions，欄位按「Select All」
    • Delivery Configuration：Format 選 XML。Period 隨意，NestEgg 會自己指定日期
    • General Configuration：Date Format 保留預設的 yyyyMMdd

    存檔後，列表上這個查詢旁邊的數字就是 Query ID。

  3. 啟用 Flex Web Service、產生金鑰

    同一頁按 Flex Web Service Configuration：

    • 勾選啟用（Flex Web Service Status）並存檔
    • 有效期限（Should Expire After）選久一點，最長一年；過期後要回來產生新的金鑰
    • IP 限制先留空：家裡網路的 IP 常會變動，設了之後 IP 一變就連不上
    • 按 Generate New Token，把產生的金鑰複製下來

    這把金鑰只能下載 Flex 報表，不能查即時資料、也不能下單。

  4. 連線並同步

    IB 一次最多查一年，又有查詢次數限制，匯入好幾年的紀錄要等一兩分鐘。金鑰與 Query ID 會用系統鑰匙圈加密，只存在這台電腦，用來每天自動同步一次。

只記美元計價的股票與 ETF 的成交；選擇權、期貨、外匯與其他幣別的交易會略過，同步完成時會告訴你略過了什麼。美元金額用中央銀行公布的成交日匯率換成台幣，央行最晚約一週後才公布，所以最近幾天的交易會晚幾天出現。

股票分割、從其他券商轉入的持股不是成交紀錄，不會記進帳本。這個串接是照 IB 公開的文件寫的，還沒用真實帳戶驗證過；同步結果怪怪的請回報。
