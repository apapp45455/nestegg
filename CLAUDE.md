# NestEgg: instructions for Claude

## Language

Write everything in this repository strictly in English:

- Documentation: README.md, CLAUDE.md, and any other Markdown or docs files
- Code comments, in every language (JS, CJS, HTML, CSS, YAML)
- Commit messages
- Pull request titles and descriptions, and replies on pull requests

Exceptions:

- README.md keeps a Traditional Chinese translation below the English version. English is the source of truth: update the English first, then bring the Chinese translation in line in the same change.
- Text the app shows to users (UI labels, messages, errors) stays in Traditional Chinese, because the app is for investors in Taiwan.
- Chat replies to the user follow the user's language.
